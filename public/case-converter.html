How It Works

Case Styles Explained

UPPERCASE and lowercase

The simplest conversions. UPPERCASE turns every letter capital; lowercase turns every letter lower. Everything else — punctuation, numbers, spaces — stays the same.

Hello World → HELLO WORLD → hello world

Title Case

Each word gets its first letter capitalised and the rest lowercased. This converter uses a straightforward rule — every whitespace-separated word is treated the same way, without special handling for small words like "of" or "the".

the lord of the rings → The Lord Of The Rings

Sentence case

Everything is lowercased first, then the first letter of each sentence is capitalised. A sentence ends at ., ! or ?.

HELLO WORLD. HOW ARE YOU? → Hello world. How are you?

camelCase

Words are joined with no separator. The first word is lowercase; every following word begins with a capital. Commonly used for variable names in JavaScript, Java and Swift.

hello world example → helloWorldExample

PascalCase

Like camelCase, but the first word is also capitalised. Commonly used for class names and React components.

hello world example → HelloWorldExample

snake_case

Words are lowercased and joined with underscores. The convention in Python, Ruby and SQL.

Hello World Example → hello_world_example

kebab-case

Words are lowercased and joined with hyphens. Commonly used for CSS class names, HTML attributes and URL slugs.

Hello World Example → hello-world-example

CONSTANT_CASE

All uppercase, joined with underscores. Used for constants in most programming languages.

max retry count → MAX_RETRY_COUNT

dot.case

Words lowercased and joined with dots. Sometimes used for namespaced config keys or nested object paths.

user profile name → user.profile.name

aLtErNaTiNg cAsE

Letters alternate between lower and upper. The original spacing and punctuation are preserved. Used to convey sarcasm or emphasis in informal writing.

hello world → hElLo WoRlD

iNVERSE cASE

Every letter swaps its case. Uppercase becomes lowercase and vice versa. Everything else is preserved.

Hello World → hELLO wORLD

Reverse

All characters are reversed. Useful for puzzles, obfuscation, or quick text transforms.

hello → olleh

Questions

Case FAQ

What is Title Case?

Title Case capitalises the first letter of each word. This converter uses a simple rule: every whitespace-separated word gets its first letter upper-cased and the rest lower-cased. It does not apply the more complex rules some publishers use for small words like "of" or "the".

What is Sentence case?

Sentence case lowercases everything, then capitalises the first letter of each sentence. A sentence ends at ., ! or ?. The very first letter of the text is always capitalised.

What is camelCase?

camelCase joins words together with no separator. The first word is lowercase, the rest have their first letter uppercase. Example: helloWorldExample. Common in JavaScript, Java and Swift.

What is snake_case?

snake_case replaces spaces with underscores and lowercases everything. Example: hello_world_example. Common in Python, Ruby and SQL.

What is kebab-case?

kebab-case replaces spaces with hyphens and lowercases everything. Example: hello-world-example. Common in CSS class names and URL slugs.

What is CONSTANT_CASE?

CONSTANT_CASE is all uppercase with words joined by underscores. Example: HELLO_WORLD_EXAMPLE. Common for constants in most programming languages.

Does the tool handle punctuation?

Yes. Punctuation is preserved in UPPERCASE, lowercase, Title Case and Sentence case. It is stripped in camelCase, snake_case, kebab-case, CONSTANT_CASE and dot.case, which are designed for code identifiers where punctuation is not allowed.

Is my text stored anywhere?

No. Everything runs in your browser. Your text is never uploaded or logged.
