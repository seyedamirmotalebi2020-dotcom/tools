How It Works

QR Codes Explained

What is a QR code?

A QR code (Quick Response code) is a two-dimensional barcode that stores data in a grid of black and white squares. A scanner reads the pattern and reconstructs the original data — text, a URL, contact details, a Wi-Fi password, or anything else that fits.

Static vs dynamic QR codes

This generator creates static QR codes. The data is encoded directly into the pattern. There is no server, no redirect and no expiry — the QR code works forever as long as the data it encodes is still valid.

Dynamic QR codes (used by some commercial services) encode a short URL that redirects to your real destination. The redirect can be changed later, but the QR code stops working if the service shuts down. For most uses, static is better.

Error correction

QR codes include redundant data so they can still be read if part of the pattern is damaged. There are four levels:

  • L (Low) — 7% of the code can be damaged and it will still scan.
  • M (Medium) — 15%. A good default for most uses.
  • Q (Quartile) — 25%. Better tolerance for dirty or damaged prints.
  • H (High) — 30%. Best for logos, tiny prints, or outdoor use.

Higher error correction makes the QR code denser (more modules), so the code has to be larger to scan from the same distance.

Sizing for print

A common rule of thumb: the printed QR code should be at least one tenth the scanning distance. For scanning from 30 cm, make the code at least 3 cm wide. For a poster scanned from 3 metres, make it at least 30 cm wide. Increase the size further if the error correction is low or the content is long.

Quiet zone

QR codes need a margin — a "quiet zone" — around them so scanners can distinguish the code from its surroundings. The standard is 4 modules wide. Keep this option on unless you have a specific reason to remove it.

Colours

Dark modules on a light background scan most reliably. If you customise the colours, keep high contrast between foreground and background and avoid inverting (light modules on a dark background) — some scanners handle inversion, many do not.

Questions

QR Code FAQ

Are the QR codes permanent?

Yes. This generator encodes your data directly into the image. The QR code is a static, self-contained image and does not rely on any server or redirect. It will keep working as long as the data it encodes remains valid.

What error correction level should I use?

M (15%) is a good default. Use H (30%) if you plan to print at small sizes, print on uneven surfaces, or overlay a logo. Higher levels make the QR code denser but more tolerant of damage.

Can I use QR codes commercially?

Yes. QR codes are an open standard (ISO/IEC 18004). The codes you generate here are yours to use freely, including for commercial purposes.

How big should the printed QR code be?

A common rule of thumb: the QR code should be at least one tenth the scanning distance. For scanning from 30 cm, make it at least 3 cm wide. For a poster scanned from 3 metres, make it at least 30 cm wide.

Does the QR code expire?

No. Static QR codes never expire. They encode the data itself, not a link to a server that might be shut down.

Is my data sent to a server?

No. The QR code is generated entirely in your browser. The text, URL or vCard you type is never uploaded, logged or stored.

Why does the QR code get denser with more text?

QR codes have a fixed number of modules per version. More data needs more modules, so the code becomes denser. Longer URLs or vCards produce visibly busier QR codes. Keep data short where possible — short URLs scan faster and more reliably.

Can I add a logo in the middle?

Not in this generator. Logos usually require error correction level H (30%) so the code still scans when part of the pattern is covered. If you add a logo with an external tool, generate the QR code here at level H, then overlay the logo carefully — the code will tolerate up to 30% coverage.
